Owner: M4 Zhu Wenyu. Status: **evidence for STCN-105 (G3-M4.1)**, produced 2026-10-13 on

The G0 oracle inventory (`docs/swe5001/security/label-workflow-oracle-inventory.md`) named the
baseline stored procedures and the tests that exercised them. This document maps each of those rows
to the Java transaction test that now replaces it. All tests run against real MySQL 8.4 (and, for the
consumer rows, real RabbitMQ) in `services/label-workflow`.

## Semantic deltas that are deliberate, not gaps

- The baseline `sp_publish_label` updated `product.current_published_label_version_id`; the target
  retires that cross-boundary write and keeps the single-current-publication invariant inside Label
  Workflow (`uk_label_one_current`), which the equivalence tests assert.
- The baseline compared the creator against the actor for **every** decision; BR-06 only forbids the
  creator from **approving**, and that narrower rule is what the Java transaction enforces.
- The oracle forced one real fix: `submit` originally had no newer-version guard, so a draft created
  after the service precheck could still be submitted. It now returns 409 and rolls back every effect.
